# PinShot UI 改版设计

> 目标：解决「看起来老旧」的问题。不是换皮，而是给 PinShot 一套自己的视觉语言：
> **Capture instrument** —— 暖石墨中性色 + 信号橙，像一台安静、精密的截图仪器。

## 0. 现状诊断（旧版）

| 问题 | 具体表现 |
| --- | --- |
| 没有品牌感 | 纯白底 + 系统默认控件，和任意一个 demo 设置窗没有区别 |
| 层级扁平 | 6 个区块全部用同一种灰色描边盒子，卡片、区块、行之间没有强弱 |
| 控件显旧 | 默认 NSSwitch / NSSlider / 描边按钮，圆角与间距不统一 |
| 空间浪费 | 560pt 宽 + 大段留白，信息挤在左侧，右侧空；标题栏没有任何作用 |
| 缺少焦点 | 没有主行动按钮，没有版本 / 权限状态层级，首次打开不知道先做什么 |
| 字体单一 | 全部 13pt 系统字，没有标题字阶，快捷键用普通字体 |

## 1. 视觉语言

**关键词**：石墨、纸感、信号橙、裁切标记、键帽。

- **中性色**：暖石墨（不是纯黑 / 纯白），浅色 `#F4F3F0`，深色 `#171614`，卡片比底色亮一档。
- **强调色**：信号橙 `#E8551F`（浅色）/ `#FF7A45`（深色），来自 App 图标上的图钉。只用于选中态、主按钮、关键数字、焦点环。
- **字体**：标题用 SF Rounded（`display()`），正文 SF Pro Text，快捷键和数字用 SF Mono。三层字阶：22 / 13 / 11。
- **形状**：卡片 14pt 圆角、控件 8–9pt 圆角、无重描边（1px 低对比边框），没有多余阴影。
- **记忆点**：**键帽**（快捷键 ⇧⌘2 做成实体键帽）与 **裁切角标**（选区四角的橙色 L 形标记）。只在这两处用力，其余保持安静。

## 3. 设置窗口（重做重点）

从「单列表单」改为**侧边栏导航 + 内容面板**，类似现代 macOS 工具：

```
┌──────────────────────────────────────────────────────────────┐
│  ● ● ●                                                       │
│ ┌────────────┐ ┌───────────────────────────────────────────┐ │
│ │  [icon]    │ │  截图                                      │ │
│ │  PinShot   │ │  用两个快捷键完成截图的两种落点             │ │
│ │  截图挂件   │ │                                           │ │
│ │            │ │  ┌──────────────────────────────────────┐ │ │
│ │ ▸ 截图      │ │  │  截图并贴图              [⇧⌘2] [录制]  │ │ │
│ │   贴图      │ │  │  截图后立即钉在屏幕上                 │ │ │
│ │   启动与权限 │ │  ├──────────────────────────────────────┤ │ │
│ │   关于      │ │  │  截图并复制              [⇧⌘1] [录制]  │ │ │
│ │            │ │  └──────────────────────────────────────┘ │ │
│ │            │ │                                           │ │
│ │ ● 已授权    │ │  ┌──────────────────────────────────────┐ │ │
│ │ v1.0.0     │ │  │ 自动隐藏 / 延迟 / 透明度 / 穿透 …      │ │ │
│ └────────────┘ └───────────────────────────────────────────┘ │
└──────────────────────────────────────────────────────────────┘
```

- 侧边栏：App 图标 56pt 圆角方块 + PinShot（18 rounded）+「截图挂件」+ 4 个导航项（图标 15pt，选中态 = accentSoft 胶囊 + 橙字）；底部权限状态 + 版本号。
- 内容页：大标题 + 一句说明；卡片（`PSTheme.makeCard()`）内为 50pt 行（标题 13 + 说明 11 + 右侧控件），行间 1px 分隔线，卡片之间 22pt 间距，页面底部 32pt 留白。
- 导航页：**截图**（两个快捷键录制行 + 使用提示）、**贴图**（自动隐藏开关、延迟滑杆、幽灵透明度滑杆、完全隐藏、点击穿透；外观：边框、阴影）、**启动与权限**（登录启动、屏幕录制状态、打开设置、重新检查、恢复默认）、**关于**（图标、版本、两个快捷键、设计说明/目录）。
- 快捷键录制：点击后行内显示「按下新的快捷键」+ 橙色描边，键帽实时预览；ESC 取消；冲突时行内红字提示（不用弹窗打断）。
- 主色只出现在：选中导航项、开关开启、滑杆已填充、主按钮、焦点环、录制态。

### 控件规范（已落在 `Sources/UI/Controls.swift`）

- `PinSwitch`：38×22 胶囊，开启橙、关闭灰，白色滑块 0.14s 缓动；支持键盘 Space。
- `PinSlider`：4pt 轨道 + 橙色填充 + 18pt 白色滑块，hover 橙色光晕；左右键微调。
- `PinButton`：`.primary`（橙底白字）、`.secondary`（键帽底 + 边框）、`.text`（橙色文字 + hover 浅橙底）。
- `KeycapView`：等宽字 + 键帽底 + 1px 边框，22pt 高。
- `PinCardView`：14pt 圆角卡片，1px 低对比边框，无阴影。

## 4. 首次引导窗口（替换系统 NSAlert）

- 620×470 无边框圆角窗口（22pt 圆角），窗口阴影，居中，可拖动。
- 内容：App 图标 88pt →「PinShot」30 rounded →「把截图钉在屏幕最上层」→ 三行能力说明（带图标徽章）：`⇧⌘2 框选截图`、`离开自动淡出 · 悬停恢复`、`复制 / 存储 / 缩放都在挂件上`。
- 底部：屏幕录制权限状态（圆点 + 文案 + 去设置文字按钮）+ 主按钮「开始使用」+ 次按钮「打开设置」。
- ESC / 关闭按钮可关闭；首次启动出现一次（`hasCompletedOnboarding`）。

## 5. 权限引导窗口（替换系统 NSAlert）

- 同一套卡片语言，560×430：图标（屏幕录制）→ 标题「需要屏幕录制权限」→ 三个步骤（1 打开系统设置 / 2 勾选 PinShot / 3 重启应用）→ 主按钮「打开系统设置」+ 文字按钮「稍后」。
- 状态实时刷新（`CGPreflightScreenCaptureAccess`）；已授权时按钮变为「已授权，开始截图」。

## 6. 贴图挂件工具栏

- 32pt 高、磨砂 `NSVisualEffectView(.hudWindow)` + 10pt 圆角 + 1px 白色 12% 边框；4 个 24pt 圆形按钮（复制 / 存储 / 自动隐藏 / 关闭），SF Symbols 12pt，hover 白色 16% 圆形底，按下 26%。
- 自动隐藏开启时「眼睛」图标为实心橙点提示状态。
- 出现 / 消失：0.12s 淡入 + 轻微上移 2pt，仅响应 hover，不打断拖拽与缩放。

## 7. 选区覆盖层

- 保留冻结帧 + 35% 遮罩；选中区域不压暗。
- 选区描边 1px 白 95%；**四角橙色 L 形裁切标记**（2pt 线宽、18pt 长），这是「截图工具」的视觉签名。
- 尺寸徽标：深色半透明胶囊，等宽数字 `392 × 248`，右侧小字 `pt`，跟随选区右下角，自动翻转/收敛。
- 顶部提示：`拖动框选` + 键帽 `ESC 取消`，居中；鼠标移动时引导线为 1px 白 12%（仅在框选过程中显示选区边延长线）。
- 空选区时保持低调，不遮挡内容。

## 8. 菜单栏

- 原生菜单保留，但每项加 SF Symbol 图标（viewfinder / doc.on.doc / eye.slash / xmark.circle / gearshape / lock.shield / info.circle / power）。
- 权限项显示状态点；无贴图时「隐藏全部 / 关闭全部」禁用。
- 「关于 PinShot」直接打开设置的「关于」页（不再弹老式 About 面板）。

## 9. 验收方式

1. `--render-ui <dir>`：离屏渲染设置窗口 4 个导航页（浅色/深色）、首次引导、权限引导 → PNG，用肉眼检查布局与对比度。
2. `--render-test`：选区覆盖层、贴图挂件渲染。
3. 真机截图：启动后打开设置，浅色/深色各截一张；检查系统标题栏、窗口圆角、控件命中。
4. 回归：`make test`、`make typecheck`、原有功能（热键 / 框选 / 贴图 / 自动隐藏 / 复制 / 关闭 / 菜单）全部通过。

### 与设计稿的偏差 / 取舍

1. 设置窗口只保留红色关闭按钮（隐藏最小化/缩放），比三色交通灯更简洁，符合“工具型设置面板”的定位。
2. `NSVisualEffectView` 的实时模糊无法在 `cacheDisplay` 离屏渲染中捕获，`--render-test` 的工具栏 PNG 用加深叠层模拟；真机为真实 HUD 毛玻璃。
3. 选区引导线为「选区四边 → 屏幕边缘」的 4 条完整线，框选过程中显示；离屏自检图里也能看到。
4. 设置窗口贴图页内容高度与可视化高度仅差约 2pt，极端字体度量下会出现滚动条（可滚动，不裁切）。
5. 本机重新构建后 TCC 屏幕录制授权会失效，需重新勾选并重启应用（ad-hoc 签名开发期特性）。
