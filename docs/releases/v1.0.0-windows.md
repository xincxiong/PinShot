# PinShot 1.0.0 for Windows (Beta)

PinShot 的 Windows 便携版：常驻系统托盘的截图贴图工具，沿用 macOS 版的暖石墨 + 信号橙视觉与核心交互。

## 下载

- `PinShot-1.0.0-windows-x64.zip`（约 151 MB）

解压后运行 `PinShot.exe`，无需安装。首次启动 Windows SmartScreen 可能提示“未知发布者”，选择「更多信息 → 仍要运行」。

## 系统要求

- Windows 10 / 11（x64）
- 无需安装运行库；Electron 运行时已打包

## 功能

- **托盘应用**：单实例；托盘菜单；无任务栏窗口。
- **区域截图**：冻结帧覆盖层，逐屏框选；按屏幕 scaleFactor 用原始像素裁剪。
- **标注编辑器**：画笔 / 直线 / 箭头 / 矩形 / 高亮 / 橡皮擦，6 色、3 档粗细、撤销重做；`Enter` 贴图、`Ctrl+C` 复制、`Ctrl+S` 保存。
- **贴图窗口**：置顶 / 桌面模式；拖动；四角等比缩放 + 尺寸徽标；悬停玻璃工具栏；右键缩放 100/75/50/25%/适合屏幕。
- **自动隐藏**：鼠标离开后淡出并点击穿透，扫回恢复；设置里可调延迟与透明度。
- **从剪贴板贴图**：`Ctrl+Shift+3` 直接标注粘贴板里的图片。
- **设置持久化**：`%APPDATA%\\PinShot\\settings.json`。

## 快捷键

| 操作 | 快捷键 |
| --- | --- |
| 截图并贴图 | `Ctrl+Shift+2` |
| 截图并复制 | `Ctrl+Shift+1` |
| 从剪贴板贴图 | `Ctrl+Shift+3` |
| 撤销 / 重做 | `Ctrl+Z` / `Ctrl+Shift+Z` |
| 完成 / 复制 / 保存 | `Enter` / `Ctrl+C` / `Ctrl+S` |

## 已知限制（Beta）

1. **桌面模式是近似实现**：Electron 无法把窗口真正插入 Windows 桌面图标层级，当前使用 `alwaysOnTop=false + skipTaskbar=true`，不置顶但仍可能位于其他普通窗口之上。
2. **未签名**：没有代码签名和安装器，SmartScreen 会提示未知发布者。
3. 暂不支持开机自启、自动更新、自定义全局快捷键。
4. 多显示器混合 DPI 下可能有 1px 级覆盖层偏移。
5. 这是 Windows 移植的 Beta 版；macOS 版功能与体验仍是主要参考。
