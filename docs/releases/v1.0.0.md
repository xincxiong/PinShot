# PinShot 1.0.0

PinShot 的第一个公开版本：一个原生 macOS 截图挂件，把截图钉在屏幕上，支持标注、缩放、挂在桌面与自动隐藏。

## 下载

- `PinShot-1.0.0-macOS-arm64.dmg` — 推荐，拖进 Applications 即可
- `PinShot-1.0.0-macOS-arm64.zip` — 解压后得到 PinShot.app

## 系统要求

- macOS 14 Sonoma 或更新版本
- Apple Silicon（arm64）

## 本次包含

- **框选即贴图**：冻结帧框选，Retina 原生像素，多显示器支持。
- **标注编辑器**：画笔 / 直线 / 箭头 / 矩形 / 高亮 / 橡皮擦，撤销重做、6 色、3 档粗细；`Enter` 完成、`⌘C` 复制、`⌘S` 保存。
- **调整大小**：四角拖拽等比缩放 + 尺寸徽标；右键 100/75/50/25% / 适合屏幕。
- **挂在桌面**：贴图可在「浮于最上层」与「桌面便签（窗口下层）」之间切换；设置里可设新贴图默认模式。
- **自动隐藏**：鼠标移开淡出、点击穿透，扫回恢复；可调延迟、透明度、完全隐藏。
- **从剪贴板贴图**：系统截图 `⇧⌃⌘4` 复制后，可直接在 PinShot 里标注 / 贴图。
- **菜单栏应用**：无 Dock 图标；快捷键 `⇧⌘2` 截图并贴图、`⇧⌘1` 截图并复制。
- **熊猫主题图标**：石墨底、熊猫脸、橙色图钉。
- MIT 开源，无第三方依赖。

## 安装与首次打开

1. 打开 DMG，把 PinShot.app 拖进 Applications。
2. 在 Applications 中右键 PinShot.app →「打开」。
   本版本使用本地 ad-hoc 签名，未做 Apple 公证，直接双击可能提示“无法验证开发者”。
   如果仍被拦截，可在终端执行：
   ```bash
   xattr -dr com.apple.quarantine /Applications/PinShot.app
   ```
3. 按引导授予「屏幕录制」权限；授权后退出并重新打开 PinShot。
4. 菜单栏点 📌 图标开始使用。

> 如果「屏幕录制」开关是开的但仍然提示未授权，请在系统设置 → 隐私与安全性 → 屏幕录制中删除旧的 PinShot 条目，再点 `+` 添加当前 App，然后重启 PinShot。
