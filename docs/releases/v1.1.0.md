# PinShot 1.1.0

PinShot 1.1.0 吸收了 Shottr 的一批高价值能力：OCR/二维码、滚动截图、窗口选择截图、文字/序号/模糊/聚光灯/取色/放大镜/测量，以及背景板。

## 下载

- `PinShot-1.1.0-macOS-arm64.dmg` — 推荐，拖进 Applications 即可
- `PinShot-1.1.0-macOS-arm64.zip` — 解压得到 PinShot.app

## 本次新增

- **OCR 与二维码**：自动离线识别中英文字，`⌘T` 打开结果面板复制；二维码 payload 可单独复制。
- **滚动截图**：框选后自动滚动拼接长图；无辅助功能权限时手动滚动兜底。
- **窗口截图**：窗口选择弹窗，截取任意窗口（排除 PinShot 自身）。
- **截图模式**：全屏截图、3/5/10 秒延时、重复上次区域、Shift 正方形选区。
- **标注工具**：文字、序号、高斯模糊/马赛克、聚光灯、取色器、像素测量、放大镜/WCAG 对比度。
- **背景板**：纸白/石墨/纯白/信号橙底 + 内边距/圆角/阴影，导出与贴图自动合成。

## 系统要求

- macOS 14 Sonoma 或更新版本
- Apple Silicon（arm64）

## 首次打开

1. 打开 DMG，将 PinShot.app 拖进 Applications。
2. 在 Applications 中右键 PinShot.app →「打开」。
   本版本为 ad-hoc 签名、未公证；如仍被拦截：
   `xattr -dr com.apple.quarantine /Applications/PinShot.app`
3. 授予「屏幕录制」权限；授权后退出并重新打开 PinShot。

> 如果屏幕录制开关是开的但仍提示未授权：在系统设置 → 隐私与安全性 → 屏幕录制中删除旧 PinShot 条目，再 `+` 添加当前 App 并重启。
