# PinShot 1.2.0

新增「分享」：截图完成后可以直接打开 macOS 系统分享面板。

## 下载

- `PinShot-1.2.0-macOS-arm64.dmg`
- `PinShot-1.2.0-macOS-arm64.zip`

## 新增：分享截图

- **标注编辑器**：底部新增分享按钮；按 `⇧⌘S` 打开系统分享面板。
- **贴图窗口**：悬停工具栏新增「分享」；右键菜单「分享…」；`⇧⌘S` 同样可用。
- 使用 macOS 原生 `NSSharingServicePicker`，可分享到 AirDrop / 信息 / 邮件 / 备忘录 / 照片 / 第三方扩展等。
- 分享的是当前合成结果：包含标注、背景板，而不是原图。

## 同时包含 1.1.0 的全部能力

OCR / 二维码、滚动截图、窗口选择截图、全屏与延时、文字与序号、模糊/马赛克、聚光灯、取色、测量、放大镜/WCAG 对比度、背景板。

## 系统要求

- macOS 14 Sonoma 或更新版本，Apple Silicon（arm64）
- 本版本 ad-hoc 签名、未公证；首次打开请右键 PinShot.app →「打开」
