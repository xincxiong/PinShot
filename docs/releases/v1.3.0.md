# PinShot 1.3.0

新增「录制 GIF」：框选屏幕区域，直接录成 GIF。

## 下载

- `PinShot-1.3.0-macOS-arm64.dmg`
- `PinShot-1.3.0-macOS-arm64.zip`

## 新增：录制 GIF

- 菜单栏 →「录制 GIF」→ 框选区域。
- 约 10fps 抓帧，默认最长 15 秒；可提前按 **RETURN** 停止，**ESC** 取消。
- 录制过程中屏幕角落显示 HUD（时长 / 帧数 / 停止按钮）。
- 停止后自动保存到桌面：`PinShot-yyyyMMdd-HHmmss.gif`。
- 同时包含 1.2.0 分享、1.1.0 的 OCR / 滚动截图 / 背景板 / 像素工具。

## 系统要求

macOS 14+，Apple Silicon。ad-hoc 签名、未公证；首次打开右键 →「打开」。
