# PinShot 1.3.1

为「录制 GIF」增加全局快捷键 **⌃⌥⌘G**。

- 按 `⌃⌥⌘G` 直接进入 GIF 框选录制，无需打开菜单栏。
- 其余行为与 1.3.0 一致：约 10fps、最长 15 秒、RETURN 停止、ESC 取消、自动保存 GIF 到桌面。
